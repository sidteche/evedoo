# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and do not harass anyone. This applies in issues, pull requests, discussions and any other project space.

## Reporting

If someone's behaviour in a project space is unacceptable, report it to the maintainer privately through the contact options on the maintainer's GitHub profile ([@sidteche](https://github.com/sidteche)). Reports are kept confidential.

The maintainer may remove comments, close threads or block accounts that break these rules.
